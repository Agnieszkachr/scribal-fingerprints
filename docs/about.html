About This Project

Project Overview

Textual critics have long described the manuscripts of the New Testament by their “character”: the Alexandrian text as short and careful, the Western text as free and expansive. These descriptions rest on selected diagnostic readings. This project asks whether they correspond to measurable, stable change profiles when the whole attested text of each witness is counted.

It is the first stage of a longer programme on the quantitative description of change profiles across the Greek New Testament. This stage builds and calibrates the method on one Gospel, John, with five witnesses: the papyrus P66 (traditionally c. 200; a third- to fourth-century date has also been argued), Codex Sinaiticus (ℵ, 4th century), Codex Vaticanus (B, 4th century), Codex Alexandrinus (A, 5th century) and Codex Bezae (D, c. 400). The comparison of the same witnesses across books is the subject of a separate study.

Every divergence of a witness from the baseline is annotated by type (addition, omission, word-order shift, morphological or lexical substitution) and embedded in its context with a Greek language model. The counted typology turns out to be the robust instrument; the contextual embeddings add little to it. The profiles describe manuscripts, which combine the text-type, the exemplar and the scribe, and are not read as the habits of individual scribes.

The accompanying article is The Typological Structure of Textual Variation: A Computational Analysis of Major Witnesses to the Gospel of John. The section numbers given on the Results page refer to it.

A Note on the Repository Name

The repository keeps its original working name, scribal-fingerprints. Because a profile combines the text-type, the exemplar and the scribe, and the design cannot separate them, the article and this site speak of manuscript-level profiles rather than scribal fingerprints (article § 6.2).

Data Sources

The texts are the TEI XML transcriptions of the ITSEE (Institute for Textual Scholarship and Electronic Editing, University of Birmingham). Only the first hand of each witness is read; corrections are ignored. The lemma lexicon is derived from MorphGNT (SBL edition, Tauber 2017), and the contextual embeddings are computed with Ancient-Greek-BERT.

Researcher

Agnieszka B. Ziemińska, Centre for Digital Humanities, Institute of Literary Research of the Polish Academy of Sciences (CHC IBL PAN), Warsaw. She works at the intersection of computational stylometry, digital philology and New Testament textual criticism.

Code & Reproducibility

The complete pipeline is open source on GitHub. The README lists the commands in the order in which they reproduce every table and figure; the Methodology page describes what each step does.

This website is a static HTML/CSS/JS application. Its data files are written from the pipeline outputs by docs/prepare_website_data.py, and it is served from the docs/ directory of the main branch via GitHub Pages.
